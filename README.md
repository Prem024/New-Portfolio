# Prem Nanda — Premium Developer Portfolio

A modern, minimal, editorial-style developer portfolio website for **Prem Nanda**, an AI-Enhanced MERN Stack Developer based in Ahmedabad, Gujarat, India.

Built with **React 18**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**, inspired by the visual design language of high-performance developer portfolios (minimalist dark charcoal aesthetic, crisp typography, clean borders, live telemetry badges, and deep architecture breakdowns).

## ✨ Features & Architecture

1. **Navigation:** Sticky header with backdrop blur, brand monogram, active scrollspy navigation, mobile drawer, and resume viewer modal.
2. **Hero Section:** High-impact editorial headline, selected word highlights, live developer availability indicator, Ahmedabad base tag, and animated scroll prompt.
3. **Selected Work (Projects):**
   - **Project 01 — TRK Finance:** Finance & loan management CRM with PostgreSQL, Redis cache layer, and dynamic EMI schedule calculation.
   - **Project 02 — Lead & Loan Document Management System:** Full-stack workflow platform with secure authentication, Google Drive integration, node-cron scheduled reminders, and document approval pipeline.
   - **Project 03 — EstateAI:** AI-powered conversational real estate exploration prototype using semantic matching and MongoDB.
   - Interactive system architecture mockups & detailed project modal.
4. **Skills & Capabilities:** Categorized layout across Frontend, Backend, Database Systems, Development Tools & AI, and Deployment.
5. **Professional Journey (Experience):** Vertical timeline showcasing role as Backend Software Engineer / MERN Stack Developer at Azentra Technologies.
6. **About Me:** Professional background, core engineering philosophy, and education (BCA – Vidhyasagar Infotech & MERN Stack Development).
7. **Development Approach:** 4-stage engineering lifecycle (01 Understand, 02 Design, 03 Develop, 04 Deliver).
8. **Contact Section:** Fully validated contact form, copy-to-clipboard email interaction, response time indicator, and social channels.
9. **SEO & Structured Data:** Person schema (JSON-LD), Open Graph metadata, Twitter cards, and SVG favicon.

## 💻 Getting Started Locally

```bash
# 1. Clone repository
git clone https://github.com/premnanda/portfolio.git
cd portfolio

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Build for production
npm run build

# 5. Preview production build
npm run preview
```
